# 개발 PC 사용 중 발견한 문제 3건 (2026-10-02)

개발 PC(Windows, `scripts/gemini-ollama.ps1`)에서 대화형으로 쓰다가 나온 문제와
조치.

## 1. 실행할 때마다 npm install 창이 뜸

- 원인: CLI 자동 업데이트. 번들은 0.61.0 고정인데 npm 레지스트리의
  `@google/gemini-cli` 최신 버전과 비교해 매번
  `npm install -g @google/gemini-cli@<최신>`을 별도 창으로 실행했다. 포크가
  아니라 전역 원본이 재설치된다.
- 조치
  - `packages/cli/src/ui/utils/updateCheck.ts`: Ollama
    모드(`GEMINI_OLLAMA_BASE_URL` 설정)면 업데이트 확인을 건너뛴다.
  - 개발 PC `~/.gemini/settings.json`에 `enableAutoUpdate`,
    `enableAutoUpdateNotification`을 false로 설정(저장소 밖).
- 참고: `GEMINI_CLI_SYSTEM_SETTINGS_PATH`로 실행기 전용 설정 파일을 지정하는
  방법은 쓸 수 없다. 관리자 소유가 아닌 폴더의 시스템 설정 파일은 CLI가 보안
  경고를 내고 무시한다.

## 2. 도구 호출 앞뒤 설명이 영어로 나옴

- 증상: 최종 답변은 한국어인데 "I'll create…", "Let me…" 같은 중간 설명이 영어.
  가끔 중국어.
- 원인: 시스템 프롬프트(약 38KB)와 세션 컨텍스트가 모두 영어라 `GEMINI.md`의
  한국어 지시가 밀린다. 모델은 직전 대화의 언어를 따라가므로 첫 턴이 영어면 그
  세션은 계속 영어로 간다.
- 측정(qwen3-coder:30b, 실제 첫 턴 요청을 Ollama에 재전송, 한국어로 시작한 비율)

  | 방식                                                | 결과                                  |
  | --------------------------------------------------- | ------------------------------------- |
  | 지시 없음(GEMINI.md만)                              | 0/5                                   |
  | 영어 지시문을 시스템 끝 + 사용자 메시지 끝에 덧붙임 | 9/15                                  |
  | 한국어 지시문으로 덧붙임                            | 4/5, 예시 포함 시 3/11                |
  | 지시문 + 한국어 예시 문장                           | 10/12 (나머지는 중국어)               |
  | 맨 끝에 system 메시지 추가                          | 2/12                                  |
  | temperature 0.3                                     | 7/12                                  |
  | **대화 맨 앞에 한국어 문답 한 쌍 삽입**             | **20/20**, 도구 결과가 쌓인 뒤 턴 8/8 |

- 조치: `GEMINI_OLLAMA_RESPONSE_LANGUAGE=ko`를 주면 `toOllamaMessages`가 시스템
  메시지 바로 뒤에 한국어 문답(사용자 요청 + 모델의 수락)을 끼워 넣는다.
  기록(history)에는 넣지 않고 보내는 요청에만 넣으며, MAIN·SUBAGENT 호출에만
  적용한다(분류·요약 등 유틸리티 호출 제외).
  - `packages/core/src/core/ollamaConfig.ts`, `ollamaContentGenerator.ts`
  - `scripts/gemini-ollama.ps1`,
    `scripts/ollama-offline/files/config/gemini.env.sample`에 기본값 `ko` 추가
- 한계: 이미 영어로 진행된 세션을 이어 가면(기록이 영어) 문답을 넣어도 영어가
  유지된다(0/6). 새 세션으로 시작해야 한다.
- 확인: `-p --output-format stream-json`으로 3회 실행, 중간 설명 전부 한국어.

## 3. 셸 출력 박스에서 한글이 "매 개 변 수"처럼 벌어짐

- 원인: `packages/core/src/utils/terminalSerializer.ts`가 2칸 문자의 둘째 칸(폭
  0, 내용 없음)을 공백으로 채웠다.
- 조치: 폭 0인 칸은 건너뛴다. 테스트 추가.
- 박스 안의 오류 자체(`ls -la` → `Get-ChildItem`에 `-la` 매개변수 없음)는 모델이
  리눅스식 명령을 쓴 것이고 다음 턴에서 스스로 고친다. 이번 조치 대상이 아니다.

## 빌드 주의

`npm run bundle`은 `packages/core/dist`를 다시 만들지 않는다. core 소스를
고쳤으면 `npm run build --workspace=@google/gemini-cli-core`를 먼저 실행해야
번들에 반영된다(cli 소스는 바로 반영됨).
